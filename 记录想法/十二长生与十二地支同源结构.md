一、核心命题

本体系把“结构先于象”作为理解十二长生、十二地支与大六壬的底层原则。不是先有寅木、午火、戌土等孤立象义，再把它们拼接成规则；而是先有天地气化运动，运动经阴阳分化、四象展开，形成十二个连续相位。十二长生描述这套十二相运动结构；十二地支则是在自然时空正位中，为这些结构填入具体自然之象后的十二个时空气化场。

可以概括为：运动 → 阴阳 → 四象 → 十二相位／十二长生结构 → 自然正位填象 → 十二地支。

因此，六壬“重地支”本质上首先是“重结构”：地支不是标签集合，而是已经被自然具象化的运动相位。

二、十二长生的定义：一个长生系统只属于一个主体

十二长生不是“人的十二阶段”专属模型，也不是十二地支各自拥有的固定标签。它描述的是某一个具体事物、五行或过程，在完整循环中依次经历的十二种状态：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。

古人以人的生命阶段命名，是因为天地人遵循同一种气化规律；人不是被拿来强行比喻自然，而是人与天地本来就在同一套运动结构之内。故十二长生既可用于人，也可用于五行、四时和其他过程。

必须严格区分：
1. 地支是固定的十二时空位置／气化场。
2. 十二长生是某一主体经过十二支时的相对生命相位。
3. 同一个地支，对不同主体可以对应完全不同的长生阶段。
4. 不能把火的十二长生阶段直接贴成十二地支的永久本义。

三、自然正位：以土为基准，火与土同相位形成火土同宫

当前体系以一年四季的自然流转作为正位观察窗口。准确来说，土首先承担自然四季与整体节律的基准，其十二长生正位与十二月自然节气直接重合；火的十二长生相位与土完全一致，因此形成“火土同宫”这一结构：

寅长生 → 卯沐浴 → 辰冠带 → 巳临官 → 午帝旺 → 未衰 → 申病 → 酉死 → 戌墓 → 亥绝 → 子胎 → 丑养。

这里的意义不是“寅永远等于长生、卯永远等于沐浴”，而是：先以土为自然正位基准建立十二相，再看到火与土完全同相位，因此火也共享这一正位序列。火土同宫不是“土跟着火走”，而是土为基准、火与其相位重合。这个自然正位可以帮助反推十二个阶段本身的动力学含义。

其中必须保留以下纠正：
- 长生不是“来到世界”。胎、养已经先完成了潜在生成与蓄养；长生是已有内质开始现实生长。
- 帝旺不是“完成”。临官是现实发生、执事；帝旺是发生后的力量凝实、具现并达到本体强度顶点。帝旺之后仍有衰、病、死、墓。
- 墓不是简单消失，而是经过衰、病、死后进入收藏、封存、转化。

四、木、金、水：同一十二相结构的相位平移

木、火、金、水不是四套彼此无关的十二长生，而是同一套十二相运动结构，在四季自然场中具有不同相位起点。

四行长生位：
木长生亥；火长生寅；金长生巳；水长生申。

四个长生点彼此相隔三支，表现出四象之间约四分之一周期的相位差。于是木、金、水也都由同一组十二地支构成自己的完整十二长生，只是相对于自然正位发生整体相位平移。

所以：
- 火在午帝旺，不代表木、金、水在午也帝旺。
- 卯、午、酉、子之所以同为四仲，不应拿火系统中的“沐浴、帝旺、死、胎”硬凑共同性质；它们分别是木、火、金、水各自的帝旺位。
- 辰、未、戌、丑分别是水、木、火、金的墓库位。

五、三合的本质：一个主体生命结构的三个关键锚点

三合不是三个地支合起来“制造”一种五行，而是同一主体十二长生中的三个高信息节点：长生—帝旺—墓。

木：亥—卯—未；
火：寅—午—戌；
金：巳—酉—丑；
水：申—子—辰。

帝旺决定“谁是主角”。长生、帝旺、墓不是三个并列事物，而是同一主体在三个生命相位上的状态。帝旺之所以居中心，是因为主体本身的五行性质、所在支的主场性质与生命周期力量顶点在此重合。

因此“三合是以帝旺之物为焦点的生命故事”应严格理解为：三合抽取的是主角十二长生中的三个关键坐标，而不是完整十二阶段，也不是简单的五行相生链。

六、十二地支的形成：给结构填入自然之象

十二长生提供的是抽象运动结构；十二地支则是这些结构在自然节气正位中的具体化。地支的木、火、金、水、寒热、升降、聚散、生长收藏等象，不应被理解为先验贴上的字典，而应视为自然在对应相位中的现实表现。

因此象义是结构的显现，不是结构的来源。研究地支应优先问：该位置在运动中承担什么功能、处于何种相位、与哪些主体的长生系统发生什么关系；然后再从自然物候、五行与传统类象中提取具体象。

七、六壬为何“重结构”

大六壬以十二地支搭建天地盘，说明其底层要表达的不是孤立象义，而是十二相位结构在特定时空中的重新对应。天地盘可理解为两个十二相位场之间的映射：地盘给出正位背景，天盘给出当前时空中结构的重新落位与对应。

因此：
- 地支—天地盘首先负责结构、本体关系、矛盾配置与运动路径；
- 四课是围绕日辰切出的局部结构截面；
- 三传是结构运动的展开；
- 类象与天干是在已确定结构之上的进一步显化与具体化。

“六壬重地支”的底层含义可以进一步概括为：六壬先读运动结构，再读结构所显之象。结构先于象，象不能反过来篡改结构。

八、研究纪律与后续问题

1. 不得把一个主体的十二长生错当成十二地支的唯一固定定义。
2. 不得把长生等同于出生、帝旺等同于完成、墓等同于消失。
3. 四孟、四仲、四季的共同性质应从多套十二长生在十二支上的交叉结构中研究，不能只用火的一套序列硬解释。
4. 土为自然正位基准、火与土同相位形成火土同宫，以及木金水相对于该正位产生相位差，是当前底层模型的重要结构，应继续用四时、藏干、十干阴阳、三合及实占结构交叉验证。
5. 阴干十二长生逆行属于下一层问题，不能在基础定义尚未稳定时反过来污染十二长生的原始结构定义。
6. 后续重点：研究十二个长生阶段的严格动力学含义；研究四象与四行相位差；研究三合、孟仲季、藏干、十干阴阳如何从同一运动结构自然推出。

一句话总纲：先有运动，运动分阴阳四象并形成十二相结构；十二长生描述“一个东西怎样经过十二相”，十二地支描述“十二相在自然时空中具体呈现成什么场”，而大六壬正是以这些结构场之间的映射来建模现实。
